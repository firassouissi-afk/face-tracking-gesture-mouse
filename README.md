# Face/Gesture Mouse

Uses MediaPipe hand landmarks and OpenCV to move the pointer and trigger a click by pinching.

```powershell
pip install opencv-python mediapipe pyautogui
python main.py
```

Press `Q` to exit. The script controls the OS cursor, so run it intentionally.
